# fun-web-pages

收集有趣的 Web 页面，用 HTML、CSS 和 JavaScript 实现一些创意和交互。

## 页面

- [Rose Galaxy](Rose%20Galaxy/index.html)：银河风格的个人展示页，包含动态背景、图片展示和音乐播放器。

## 预览

直接打开 `Rose Galaxy/index.html`，或在仓库根目录启动静态服务：

```bash
python -m http.server 5500
```

访问 [http://localhost:5500/Rose%20Galaxy/](http://localhost:5500/Rose%20Galaxy/)。

## 目录约定

每个页面独立放在一个文件夹中，包含入口 `index.html` 和所需资源。
